# Pokédex

React + Vite, данные из [PokeAPI](https://pokeapi.co/). Тёмный технологичный минимализм, шрифты Space Grotesk и Orbitron (Google Fonts).

## Как это работает

- **Первый экран** — только интерактивная колода по центру, без текста.
- **Свайп вправо** (палец или мышь) — покемон сохраняется в избранное, экран вспыхивает зелёным.
  **Свайп влево** — карточка пропускается, экран вспыхивает красным. Стрелки ←/→ на клавиатуре делают то же.
- **Каталог** ниже: поиск, фильтр по типу (чипы), «только избранное». Стадии эволюции объединены в одну карточку, точки внизу переключают стадию. Клик по карточке открывает покемона в колоде.
- Страницы каталога подгружаются сами при прокрутке (бесконечный скролл).

## Производительность

- Данные: одна страница каталога = 1 GraphQL-запрос PokéAPI (~5 КБ) вместо десятков REST-запросов; REST остаётся запасным путём.
- Картинки: WebP нужной ширины через бесплатный ресайзер wsrv.nl (~25 КБ вместо ~150 КБ), при сбое — оригинал.
- WebGL (HoloCard) работает только у двух верхних карточек колоды, текстура одна на все карточки.
- Попап и переключатель языка (библиотека `motion`) загружаются отдельными чанками.
- Список каталога: `memo` на карточках, `content-visibility`, бесконечная подгрузка.

## Шрифты

Подключаются в `index.html` (`<link>` Google Fonts). Чтобы сменить: поменяйте семейство в ссылке и имя в переменных `--font-display`, `--font-body`, `--font-mono` в начале `src/index.css`. Первым в списке стоит основной шрифт, следующие подхватывают символы, которых в нём нет (кириллицу).

## Локализация (EN / RU)

- Интерфейс: словарь в `src/i18n/index.jsx`, выбор языка сохраняется в браузере.
- Имена покемонов: официальные русские названия из [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/List_of_Russian_Pok%C3%A9mon_names) (CC BY-NC-SA), статичный файл `src/data/ruNames.json`.
- Описания, категории и способности: в PokéAPI нет русских текстов, поэтому они переводятся бесплатно и лениво: встроенный Translator Chrome, если доступен, иначе MyMemory. Результат кэшируется в `localStorage`.
- Названия приёмов остаются английскими.

## Компоненты

- `components/reactbits/` — [React Bits](https://reactbits.dev): `SpotlightCard` (карточки каталога), `ShinyText` (подпись загрузки), `RubberSegment` (переключатель языка, нужна библиотека `motion`).
- `components/HoloCard.jsx` — React Bits `HoloCard` (WebGL-фольга) с добавленным слотом `children`.
- `components/Stack.jsx`, `hooks/useSwipe.js`, `hooks/useDeckQueue.js` — колода, свайп, очередь.
- `hooks/usePokemons.js` — цепочки эволюции + данные покемонов.
- `utils/cardTexture.js` — рисует фон и арт карточки для HoloCard.
