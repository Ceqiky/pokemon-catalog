# Контекст проекта (кратко)

React 18 + Vite 6, обычный CSS (без Tailwind). Каталог покемонов: центральная голографическая колода со свайпом, каталог с поиском/фильтром, попап с деталями, EN (по умолчанию) + RU.
Запуск: `npm i && npm run dev`, сборка: `npm run build`. Деплой: GitHub Pages (`.github/workflows/deploy.yml`, `base: "./"` в `vite.config.js`).

## Главное поведение
- Карточки в колоде переключаются **только свайпом/перетаскиванием** (кнопок Next/Shuffle нет). Вправо — в избранное (зелёное свечение), влево — пропуск (красное). Тап по карточке или свайп вверх — попап. Стрелки клавиатуры дублируют свайп.
- Колода и очередь синхронны: `useDeckQueue` (5 слоёв, `advance`, `select`, `evolve` сохраняет `uid`).
- Каталог: эволюционные семейства в одной карточке с точками стадий, бесконечный скролл, клик по карточке открывает покемона в колоде.

## Где что лежит
- `src/components/Stack.jsx/.css` — колода, значки свайпа (кольцо/бегунок), свечение `.deck-glow`, затемнение `.deck-dim`. Прогресс жеста — CSS-переменные `--p` (движение), `--rp` (кольцо, остаётся после отпускания).
- `src/hooks/useSwipe.js` — мышь через Pointer Events, **палец через нативные touch-события** (iOS Safari): порог max(80px, 30% ширины), бросок по скорости, возврат.
- `HoloCard.jsx` — WebGL2-шейдер (React Bits, изменён): режим `overlay` (без `mix-blend-mode`), живой WebGL только у слоёв ≤1, dpr ≤1.5.
- `PokemonFace.jsx` — лицевая сторона карточки. Точки эволюции и сердечко рендерятся у **всех** слоёв (иначе после свайпа макет дёргается).
- `PokemonImage.jsx` — картинки через `wsrv.nl` (WebP) с запасным оригиналом; кэш загруженных адресов, чтобы не мигали.
- `PokemonDetails.jsx` — попап (характеристики, способности, слабости, эволюции, крик, шайни). Данные через REST, RU-тексты переводятся лениво.
- `usePokemons.js` — PokeAPI GraphQL (по 16 цепочек эволюции на страницу) с REST-запасом.
- `i18n/index.jsx`, `data/ruNames.json` — переводы; машинный перевод: нативный Translator → MyMemory с кэшем в localStorage.
- `Intro.jsx`, `PikachuLoader.jsx` — интро с жидкостным силуэтом Пикачу.

## Решения и подводные камни
- На телефоне: свайп-значок по центру, `.deck-dim` затемняет экран; на десктопе (>720px и `pointer: fine`) затемнения нет. Дорогие SVG-фильтры и тени на мобильном отключены (рывки). Наклон от гироскопа **убран намеренно**.
- `content-visibility`, слушатели на карточках каталога локальные (раньше window-слушатели давали ~12 мс на pointermove).
- Lingva-перевод отрезан Cloudflare — не использовать. Нативный Translator используется только если уже создан.
- Движение уменьшается при `prefers-reduced-motion`.
- Не проверено на реальном iPhone: touch-свайп, плавность затемнения/значка, лоадер, попап (тестировал только эмуляцией в десктопном браузере).

## Ограничения
- Покемоны, имена и арт — собственность Nintendo / Game Freak / The Pokémon Company. Это фан-проект, без монетизации.
- Данные и картинки тянутся из PokeAPI и `wsrv.nl`; при их недоступности каталог не загрузится.
